### Trust Levels and Permissions

Discourse uses a trust level system (0-4) that automatically grants privileges:

| Trust Level | Name | Requirements | Abilities |
|-------------|------|--------------|-----------|
| 0 | New User | Just joined | Read, like, flag |
| 1 | Basic User | Enter 5 topics, read 30 posts, 10 minutes reading time | Reply, upload images |
| 2 | Member | Visit 15 days, read 20+ posts, 100+ reading time, receive 1+ like | Edit own posts, flag posts |
| 3 | Regular | 50% days visited (last 100 days), 20,000+ reading time, 100+ topics viewed, 500+ posts read, 10+ likes given, 10+ received | Edit all posts, first-post approval, full composer |
| 4 | Leader | Manual promotion only | Recategorize, rename, merge, split topics |

### Decision-Making Process

#### Day-to-Day Operations
- **Moderators:** Handle directly within guidelines
- **Escalations:** Consult with Community Admin
- **Technical issues:** Technical Admin handles

#### Major Decisions
Require consensus among administrators:
- Category structure changes
- Policy changes
- Feature additions/removals
- Significant customizations

**Process:**
1. Proposal submitted to admin team
2. Discussion period (minimum 3 days)
3. Vote (simple majority)
4. Implementation

#### Emergency Decisions
In case of urgent issues (security, spam attack, legal):
- Any administrator can act immediately
- Notify other admins within 1 hour
- Document decision and rationale
- Review in next admin meeting

### Onboarding Process

#### New Administrator Onboarding
1. Access provisioning (admin account, infrastructure)
2. Orientation session (2 hours)
3. Documentation review
4. Shadow existing admin (1 week)
5. Full access granted

#### New Moderator Onboarding
1. Moderator account setup
2. Moderation guidelines review
3. Tool training (flags, reviews, edits)
4. Mentor assignment (2 weeks)
5. Category assignment

### Performance and Review

#### Moderator Performance
Reviewed quarterly:
- Response time to flags
- Community feedback
- Participation in meetings
- Adherence to guidelines

#### Administrator Performance
Reviewed semi-annually:
- Platform stability and uptime
- Community satisfaction
- Goal achievement
- Collaboration effectiveness

### Conflict Resolution

#### User Conflicts
1. Moderator intervention
2. Warning or temporary suspension
3. Escalate to Community Admin if unresolved
4. Final decision by admin team

#### Team Conflicts
1. Direct communication between parties
2. Mediation by Lead Admin if needed
3. Final decision by admin consensus

### Amendments

This governance structure can be amended by:
- Proposal by any administrator
- Discussion period (minimum 7 days)
- Unanimous approval by all administrators
